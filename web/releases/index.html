Early test build. Installing to disk erases the whole disk you choose, including any other operating system on it.

1 · Check the download

sha256sum aios.img.xz      # Linux; on macOS: shasum -a 256 aios.img.xz
certutil -hashfile aios.img.xz SHA256      # Windows

It must match the sha256 above (also in aios.img.xz.sha256).

2 · Write it to a USB stick (16 GB or more)

  1. Windows, macOS or Linux: balenaEtcher or Rufus (Windows; DD mode) can write the .img.xz directly.
  2. Linux, from a terminal (replace sdX with your USB stick; everything on it is erased): 
    xzcat aios.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync

3 · Start from the USB

  1. Turn the laptop on and open its boot menu (usually F9 on HP, F12 on Dell and Lenovo, Esc or F8 on others). Choose the USB stick.
  2. First start: language, keyboard, time zone, your password and wifi. The user is aios.
  3. The AI model loads in the background: the first answer can take a minute or two.

4 · Install on the disk (optional)

  1. From AIOS running on the USB, open a terminal (Super+Enter) and run sudo aios-install.
  2. Choose the disk, check what will be erased, and type the disk name to confirm.
  3. Choose a passphrase: your files are encrypted with it and it is asked at every start. If you forget it, they cannot be recovered.
  4. When it finishes, turn the laptop off, remove the USB and turn it on.

Privacy

The AI runs on the laptop. Nothing leaves it unless you connect a remote AI provider (the assistant tells you) or send a diagnostic report with aios-diag. The report carries logs, hardware details, network names and a hardware test; never your conversations, AI keys, wifi passwords or the text of your reminders. It asks before adding your last screenshots.

Problems?

Locked screen, keyboard shortcuts and commands: see the help page (in AIOS, Super+F1). Run aios-diag on the laptop: it sends logs and a hardware self-test (never your conversations) so we can see what happened. Or write to contact@ccmai.org.
