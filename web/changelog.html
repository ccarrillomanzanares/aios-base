AIOS

changelog

v0.25.0 — 2026-10-30

download · source

the new base

  • AIOS is rebuilt from scratch on Buildroot: smaller, faster to start, and the same image boots from USB on BIOS and UEFI computers.
  • Starts straight into a sway desktop with the WarGames look and the AIOS assistant in a terminal.

local AI

  • Qwen3.5-4B runs on the laptop's CPU with llama.cpp, picking the fastest code for each processor; it can also read images (vision).
  • The context size adapts to the RAM; the fixed part of the prompt is prepared while you type, so answers start sooner.
  • Optional remote providers (your own server, OpenAI, Anthropic, Gemini, Ollama Cloud, OpenRouter, any compatible one). Keys are entered on your phone through an encrypted pairing page (/pair), never typed on screen.

the assistant

  • Runs the system through the aios command: wifi, sound, screens, Bluetooth, brightness, temperature, power, reminders and updates. It asks before changing anything.
  • Voice: hold Super+Space and speak (whisper.cpp); spoken answers with espeak. Dictation into any window with Super+Ctrl+Space.
  • /look: looks at the screen and answers about it. Clipboard: summarise or translate what you copied.
  • Chat history: /history and /resume.

the system

  • First start: language, keyboard, time zone, your own password and wifi.
  • Sound with PipeWire for every app; Bluetooth headphones, keyboards and mice.
  • Screen lock, notifications, several screens (extend or mirror), screenshots.
  • Battery: power profile when unplugged, warnings, and suspend at 3% if the charger is not plugged in.
  • Firewall that blocks incoming connections; SSH off by default.
  • aios sys selftest: hardware self-test (CPU, GPU, screens, wifi, Bluetooth, speaker and microphone, AI model, voice). aios-diag sends it with the logs.

install and updates

  • sudo aios-install: installs AIOS on the disk (erases it) with your files encrypted (LUKS2) and room for A/B updates.
  • aios update code: signed updates of the AIOS software, with a daily check and exact rollback.
  • Also as a VirtualBox appliance (aios.ova).
